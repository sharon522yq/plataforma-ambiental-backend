# Hallazgos del piloto

Registro de lo que se observa en las sesiones de [`piloto.md`](piloto.md). Sin nombres de participantes: usa «Colectivo A, persona 2».

**Gravedad:** *Bloquea* (no pudo terminar la tarea o se expone un dato), *Molesta* (terminó, pero con trabajo o confusión), *Sugerencia* (idea para después).
**Estado:** *Abierto*, *Corregido* (con el commit o PR), *Aceptado* (se decide no corregir, con el motivo).
