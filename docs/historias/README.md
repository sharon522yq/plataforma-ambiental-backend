# Historias de usuario

**Nota de honestidad:** estas historias se escribieron en la fase 11 (2026-10-29), después de construir los módulos. Durante el desarrollo los criterios vivieron en `docs/plan-de-trabajo.md` (alcance y criterio de salida de cada fase) y en las propias pruebas. Aquí se reúnen y se contrastan con el código; ningún criterio describe algo que no esté implementado y probado.
